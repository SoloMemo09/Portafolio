# Sistema CRM y POS (Punto de Venta)

Desarrollo de una plataforma web completa a medida para **Cerrajería Alba**, con el fin de digitalizar sus operaciones comerciales y la atención a clientes.

## Funcionalidades Principales

- **Gestión de Inventario:** Control preciso de existencias, productos y alertas de bajo stock.
- **Módulo de Ventas (POS):** Interfaz ágil para cajeros, permitiendo procesar transacciones rápidamente.
- **Atención al Cliente (CRM):** Historial de compras por cliente, gestión de cotizaciones y seguimiento de servicios en terreno.

## Stack Tecnológico

El proyecto fue desarrollado utilizando un stack web tradicional, priorizando la compatibilidad y facilidad de despliegue en servidores compartidos:
- **Backend:** PHP (procesamiento de lógica de negocio e interacciones con la base de datos).
- **Frontend:** HTML5, CSS y JavaScript para dotar de interactividad y dinamismo a las interfaces de usuario.


## Este proyecto tiene escalabilidad para implementar en nuevas tecnologias como el framework astro y supabase.
